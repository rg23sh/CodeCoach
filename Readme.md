# CodeCoach – Android Application

## Project Description

CodeCoach is an Android application designed to help aspiring software developers and programming enthusiasts improve their coding and problem-solving skills through coding interview challenges and AI-assisted feedback.

## Technologies

- Android Studio
- Java
- XML
- Firebase Authentication
- Google Cloud Firestore
- Firebase Cloud Functions
- OpenAI Responses API

## Project Components

### Member 1 – User Interface and Authentication
- Login and registration screens.
- Home dashboard.
- Application navigation.

### Member 2 – Coding Question Library
- Question collection.
- Question categorization.
- Difficulty filtering.
- Question descriptions and examples.

### Member 3 – Code Editor and Submission
- Coding interface.
- Source code input.
- Submission functionality.
- Submission validation.

### Member 4 – OpenAI API Integration
- Backend communication with OpenAI.
- Source code analysis.
- AI-generated feedback.
- Evaluation criteria.

### Member 5 – Firebase and Submission History
- Firebase project configuration.
- User authentication integration.
- Firestore database.
- Submission storage and retrieval.
- Submission history.

## Development Guidelines

- The Android application will be developed using Java and XML.
- Each component should be developed separately and integrated into the main application.
- All members should follow the agreed project structure.
- Changes should be tested before integration into the main application.
